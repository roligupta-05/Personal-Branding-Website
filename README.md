# Personal Branding Website

A personal portfolio website created using vibe coding, where AI generated both the code and the images from my prompts.

## About
This project was built for Lab 2 of the Generative AI course at Samsung Innovation Campus. It introduces me through three sections:

- **Who I Am**: a short introduction
- **My Skills**: what I can do
- **My Future Goal**: where I want to go

## Live Demo
https://jocular-stroopwafel-f85221.netlify.app

## Built With
- HTML5
- CSS3
- AI tools (Gemini) for code and image generation

## How I Made It
1. Wrote a personal profile with three sections
2. Generated one image per section using AI prompts
3. Prompted AI to build the full website with a chosen style, color tone and target audience (recruiters and companies)
4. Adjusted images and layout with follow-up prompts

## Run Locally
1. Download or clone this repository
2. Open `index.html` in any browser
