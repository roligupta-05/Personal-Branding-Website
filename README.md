A complete, responsive, production-quality personal portfolio website created using **vibe coding**, where AI generated both the code and the images based on my prompts.

##  About

The website presents me as a 21-year-old, second-year B.Tech Computer Science and Engineering student passionate about software development, problem-solving, and Artificial Intelligence. It is structured into clear, single-page sections:

* **Hero:** Professional introduction, concise headline, summary, and call-to-action buttons.
* **Who I Am:** Academic background, technical interests, learning philosophy, and personal approach to engineering.
* **My Skills:** Honest visual representation of C, Java, Python, DSA, HTML, CSS, JavaScript, AI/ML fundamentals, VS Code, GitHub, teamwork, leadership, and technical presentations.
* **My Projects:** Highlights my Java Library Management System with an extensible layout ready for future project additions.
* **My Future Goals:** Career roadmap focused on Java & DSA mastery, AI/ML specialization, full-stack development, and industry internships.
* **Connect With Me:** Direct interaction forms and verified social profiles.


##  Built With

* **HTML5:** Semantic markup structure for clarity and SEO optimization.
* **CSS3:** Responsive layout using CSS custom properties, smooth flex/grid structures, and an editorial design system (off-white background, charcoal text, muted sage-green accents, Lora headings, and Open Sans body text).
* **Vanilla JavaScript:** Light/Dark theme toggle, scroll animations, sticky navigation, back-to-top control, and mobile menu handling.
* **AI Tools (Gemini):** Used for full code synthesis and custom section image generation.


##  How I Made It (Vibe Coding)

1. **Content Draft:** Wrote a personal profile detailing my background, skills, projects, and career targets.
2. **AI Image Generation:** Generated one custom visual asset per core section using AI image prompts:
   - `D:\WhoIAm.png` → *Who I Am*
   - `D:\MySkills.png` → *My Skills*
   - `D:\FutureGoal.png` → *My Future Goals*
3. **AI Code Generation:** Prompted Gemini to build the entire responsive single-page website with a chosen style, color tone, and target audience (recruiters and companies).
4. **Iterative Refinement:** Adjusted image sizing, alignment, responsive behavior, theme toggles, and layout spacing through follow-up prompts.
